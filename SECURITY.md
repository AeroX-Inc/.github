
# Security Policy

## Our Commitment

AeroX takes security, privacy, and responsible disclosure seriously.

## Reporting a Vulnerability

If you discover a security vulnerability in an AeroX project, please report it privately.

**Security Contact:** YOUR-SECURITY-EMAIL

Please include:

- Vulnerability description
- Steps to reproduce
- Potential impact
- Relevant evidence

## Responsible Disclosure

Please do not publicly disclose vulnerabilities before AeroX has had a reasonable opportunity to investigate and address them.

Thank you for helping keep AeroX and its users secure.
